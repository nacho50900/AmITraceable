[[section-context-and-scope]]
== Contexto y alcance

=== Contexto de negocio

[cols="1,2,2", options="header"]
|===
| Interlocutor | Entradas a AmITraceable | Salidas de AmITraceable

| Usuario final
| Consentimiento OAuth, ninguna otra entrada manual (no hay formularios
  de datos personales)
| Informe de exposición (score, qué se puede inferir sobre ti con su
  fuente y representación visual, veredicto y conclusiones de IA)

| Reddit (Data API)
| `access_token` tras autorización del usuario
| Peticiones de lectura: perfil, posts enviados, comentarios

| Instagram (Platform API / Business Login)
| `access_token` de corta y larga duración tras autorización
| Peticiones de lectura: perfil básico, media del usuario

| X / Twitter
| _(sin integrar; tarjeta "Coming Soon" en la interfaz)_
| —

| Mistral AI (La Plateforme)
| (a) Informe de exposición ya generado (JSON, incluidas las
  recomendaciones por reglas fijas como insumo) -- se envía
  automáticamente en cuanto el informe está listo, sin acción explícita
  del usuario; (b) por separado, texto/biografía públicos, para detectar
  autodeclaraciones que las regex no reconocen
| (a) Veredicto general + conclusiones específicas en lenguaje natural;
  (b) atributos detectados en formato estructurado. Opcional: sin
  `MISTRAL_API_KEY` configurada, ninguna de las dos integraciones se usa.

| Hugging Face (dataset OSV-5M)
| _(solo en tiempo de preparación, no en tiempo de ejecución de la app)_
| Imágenes georreferenciadas de España usadas para construir el índice
  FAISS del módulo de geolocalización (`backend/scripts/`).

| SonarCloud
| Resultados de análisis estático + cobertura (`lcov.info`,
  `coverage.xml`) enviados desde el pipeline de CI
| Quality gate, métricas de calidad de código

| GitHub Actions (CI/CD)
| Push / Pull Request al repositorio
| Ejecución de tests, build, análisis Sonar, publicación de imágenes
  Docker en releases
|===

                     HTTPS

                                              |
                                              | proxy_pass /auth/*, /api/*
                                              | (mismo origen de cara al navegador --
                                              |  ver webapp/nginx.conf)
                                              v
                                  [ backend (FastAPI, Python) ]
                                              |
                     +-----------------+------+------+-----------------+
                     |                 |             |                 |
                 HTTPS OAuth       HTTPS OAuth    HTTPS REST        HTTPS REST
                  /REST                /REST      (automático,      (automático,
                     v                 v           informe)         atributos)
            [ Reddit Data API ] [ Instagram API ] [    Mistral AI API     ]
                                                              |

                                                    construido offline

            [ Prometheus ] ---- datasource ----> [ Grafana ]

Mapeo de canales:

[cols="1,2,2", options="header"]
|===
| Canal | Protocolo | Datos que transporta

| Navegador <-> webapp (Nginx)
| HTTPS
| HTML/JS/CSS estático (SPA), peticiones `fetch`/`EventSource` a rutas
  relativas (`/auth/*`, `/api/*`) -- Nginx las reenvía al backend bajo el
  mismo origen, así que de cara al navegador todo vive en un solo dominio

| webapp (Nginx) <-> backend
| HTTP interno (red Docker `monitor-net`) + JSON, cookie de sesión
  firmada (`SessionMiddleware`)
| Estado de autenticación por plataforma, informe de exposición
  (incluido vía streaming SSE)

| backend <-> Reddit / Instagram
| HTTPS (OAuth 2.0 + REST/JSON)
| Intercambio de `code` por `access_token`, lectura de perfil y
  contenido público

| backend <-> Mistral AI
| HTTPS + JSON, automático en cuanto hay informe/atributos que analizar
  (sin acción explícita del usuario)
| Informe ya generado (agregados, no publicaciones originales) o
  texto/bio públicos; respuesta con veredicto+conclusiones o atributos
  estructurados según el caso

| backend <-> índice FAISS (local)
| Acceso a disco/memoria, sin red en tiempo de ejecución
| Embeddings de imágenes de referencia de España, construidos offline
  (ver `backend/scripts/`) a partir del dataset OSV-5M de Hugging Face

| Prometheus <-> backend
| HTTP (scrape interno, red Docker `monitor-net`)
| Métricas de la instrumentación FastAPI (`/metrics`)

| Grafana <-> Prometheus
| HTTP (datasource)
| Consultas de métricas para los dashboards
|===
